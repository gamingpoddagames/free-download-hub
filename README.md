# පුංචි නැණ මඟ — Sri Lanka Grade 1–5 Education Website

**Website source:** [school/index.html](school/index.html)

Original demo grade 1–5 practice questions, printable answers, and interactive scholarship quiz. Open the HTML locally to test. Print buttons use the browser's **Save as PDF** option; no pre-generated downloadable PDF files are currently hosted in the GitHub repository.

## Publish
1. GitHub repository Settings → Pages → Build and deployment → Source: **GitHub Actions**
2. Actions → **Deploy Sinhala School Website** → Run workflow.
3. Once successful, visit https://gamingpoddagames.github.io/free-download-hub/

This repository uses an existing free-download-hub project as a starting point. The publication URL is conditional on Pages being enabled and deployment succeeding. Do not claim the site is live before checking it.
